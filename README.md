# PixelVault

PixelVault is a nostalgic, high-fidelity 8-bit retro handheld console simulator with authentic dot-matrix LCD rendering, hardware-accurate tactile controls, WebAudio chiptune synthesizer, and offline-first PWA support. Built with standard Vanilla JavaScript and CSS modules.

## Features
- **Authentic Dot-Matrix LCD Display**: 160x144 logical resolution with pixel grid and multi-theme colorways (Original DMG, Pocket Gray, Cyber Blue, Solar Amber, Iron Side).
- **5 Built-In Retro Games**:
  - **BlockFall**: Classic falling block puzzle with rotation wall-kicks and next piece sidebar preview.
  - **Bouncer**: Breakout/Arkanoid arcade paddle action with multi-tier destructible brick layouts.
  - **Rooftop Cat**: Platform runner with physics jumping, enemies, and collectible fish.
  - **Snake**: Grid-based retro serpent with smooth turn-buffering and ramping speed.
  - **Defender**: Space arcade shooter featuring scrolling parallax starfields, formation descent, and laser blasters.
- **PWA & Offline Capable**: Installable on Android, iOS, and Desktop with valid icons and resilient Service Worker caching.
- **Zero Runtime Dependencies**: 100% Vanilla ES6+ and Vanilla CSS. Built with Vite.

## Quick Start
```bash
npm install
npm run dev
```
